# 致远未来学者项目报销标准流程（个人）

> 来源：用户口述 + `2026年致远未来学者项目报销流程【20260519更新】.pdf`（2 页，含 ZIRC 审批截图示例）+ 本机 ZIRC/财务系统实测。
> 原则：所有提交、审批、支付由本人操作；MCP 只做读取/预填，绝不自动提交。

## 阶段 1：ZIRC 系统登记「经费发生」（必做，导师审批通过后才能报销）

1. 打开 <https://zirc.sjtu.edu.cn/> → 点「进入系统」（jAccount 登录后进入）。
2. 进入「我的项目」→ 选择 **2026 年致远未来学者项目**（当前账号下有 1 个有效项目）。
3. 在项目内点「**新增经费发生**」：
   - 填写报销明细、金额、发票信息；
   - 提交给**顾问导师**审批。
4. 导师审批通过后：
   - 打开审批记录，**完整截图**（要显示审批通过的信息）；
   - 截图保存并命名为 **「附件 1-审批清单」**。
5. **无须等待管理中心确认**，即可进入学校财务系统报销（管理中心确认是后续流程）。

## 阶段 2：AI 报销（学校财务）

入口：交我办 →「财务」→「我的发票(AI报销)」，或直接打开
`https://apply.jdcw.sjtu.edu.cn/my_invoice/?locale=zh`（实际报销表单在 `apply.jdcw.sjtu.edu.cn/finance-claim/ui/home`）。

1. **上传发票**：上传 PDF 增值税发票；
2. **给每张发票加附件**：
   - 每张发票都必须附上对应事项的 **「附件 1-审批清单」截图**（ZIRC 审批通过记录）；
   - 单张/单笔 **超过 1000 元** 还需附 **支付记录**（微信/支付宝/银行卡流水截图）；
3. **选择发票**：勾选要报销的发票；**同一类事项可以多张一起选**；
4. **项目选择**：**致远未来学者**（项目名/编号以财务系统列表为准）；
5. **支付信息**：选择 **我的银行卡**（已有收款卡，不从别处填卡号）；
6. **非发票附件**：按费用类型上传对应材料，例如：
   - 打车：**行程单**；
   - 其他类型按财务要求补附件；
7. **摘要**（严格按格式写清楚）：
   ```
   2026致远未来学者计划本人组（顾问导师：导师）成员xxx报xxx费用，用于xxx
   ```
   示例：`2026致远未来学者计划本人组（顾问导师：导师）成员本人报市内交通费，用于前往XX实验/调研`
8. 核对金额、发票、附件、项目、银行卡后，由**本人点击提交**。

## 与 MCP 工具的关系

- `reimburse_prefill` 已支持：按发票关键词选已有发票、选择经费/项目（支持「致远未来学者」名称）、填摘要（把上面完整格式传给 `description`），并**停在提交前**；
- **未自动化的部分**：审批清单/支付记录/行程单等附件上传、多发票勾选、>1000 元支付记录校验、ZIRC 的新增经费发生提交——这些仍由本人完成；
- ZIRC 阶段未做自动化工具（系统为 iframe 框架页，新增经费发生属审批写操作）；当前只验证了登录与读取页面。

## 精确导航与表单实测（2026-10-19 补齐）

系统为框架页（`iframe_crmeb_main`），直接打开内页 URL 会跳回首页；需在系统左侧/顶部菜单内操作。

**精确路径（实测可达）**

1. 打开 `https://zirc.sjtu.edu.cn/` → 点「进入系统」进入 `/Public/login` 后的系统首页；
2. 顶部/侧边选「致远未来学者项目」→「我的项目」（`/Projectsmy/indexmy/`）；
3. 我的项目列表中项目行：`[ZIRC20XX-XX] 某研究项目`（导师：导师；成员：本人、成员B、成员C；预算 XXXXX；状态：审核通过）；
4. 点该行「操作」列的查看/修改按钮，进入项目详情 `/Projects/detail/tag/<project-tag>`；
5. 项目详情页点「**新增经费发生**」（实际链接 `/Projects/editjf/tag/<project-tag>`）；
6. 在「新增经费发生」弹窗中填写：
   - **类型**（select，name=`name`）：材料费 / 测试化验加工费 / 交通费 / 国内差旅费 / 会议费 / 邮寄费 / 培训费 / 其他 / 办公及印刷费 / 劳务费 / 因公出境差旅费；
   - **金额**（input，name=`je`）；
   - **说明**（textarea，name=`comment`，id=`task`）；
   - **发票号**（input，name=`fph`）；
   - 页面会显示「当前剩余预算 / 该类型预算额 / 冻结预算 / 可用预算」；
7. 点「**提交审批**」（button onclick=`jcje()`）提交给导师——**必须由本人确认后点击，MCP 不代提交**。

**实测记录**：上述详情页与新增经费发生弹窗均已打开并读取字段；**未填写、未点提交审批、未产生任何数据**。截图：`artifacts/zirc-test/project-detail.png`、`artifacts/zirc-test/add-expense-form.png`。

## MCP 工具：ZIRC 预填（新增 2026-10-19）

- `zirc_project_get`：读取指定项目编号（默认 ZIRC20XX-XX）的项目行信息并解析详情 tag；实测成功（导师导师、成员本人/成员B/成员C、预算 XXXXX、审核通过）。
- `zirc_expense_prefill`：自动进入项目详情 → 打开「新增经费发生」→ 预填 **类型 / 金额 / 说明 / 发票号** → **停在「提交审批」前**，返回字段与截图；不会提交、不会审批。
- 实测（用 0.01 元 + TEST-0001 的占位值）：返回 `status:"prefilled_awaiting_submit"`、`submitted:false`，截图 `%LOCALAPPDATA%\sjtu-mcp\artifacts\zirc\zirc-expense-prefill-*.png`；测试表单随后已关闭，未产生任何数据。
- 用法示例（DSH 中）：
  > 帮我预填 ZIRC 经费发生：类型 交通费，金额 XX.XX，说明「2026致远未来学者计划本人组（顾问导师：导师）成员本人报市内交通费，用于前往实验室」，发票号 xxxxx。

## 关于 iframe 保护

ZIRC 内页含 `if(top==self)` 保护，直接开内页 URL 会跳回首页。工具通过系统自身的 `iframe_crmeb_main` 框架加载内页（`frame.goto`），因此可正常操作；这不是绕过权限，只是按系统设计在框架内使用。
